## Требования и объём

Довести существующую библиотеку и demo до обновлённого лицензированного SnowUI Figma. Согласованные исключения (контрастные цвета, читаемое меню, корректная числовая шкала) сохранять только если автор не устранил исходную проблему. Проверять композицию, геометрию, типографику, изображения, иконки и состояния.

Объём: существующие компоненты и состояния в обеих темах; Dashboard, Sign In A, Account Settings; отдельная панель Settings со всеми семью разделами. Новые приложения из кита не входят в задачу. Для расширений без отдельного макета (Accordion, Alert, AlertDialog, AvatarGroup, Progress, Scheduler, Sheet, Skeleton, Spinner, Sparkline) сверяются общие примитивы, токены и состояния.

## Сверка с обновлённой библиотекой

Пользователь поручил применить library updates и повторно оценить все три исключения: сохранять их только там, где автор не исправил проблему. В native Figma применены 502 обновления и завершающее обновление Colors. После этого Updates с включённым Show updates for all pages сообщает No updates available; доказательство `library-updates-all-pages-complete.png`.

Первая обновлённая полная копия содержит 143598 узлов (предыдущая — 120610). Сопоставлены все 573 прямых варианта, 22 составных экрана и 14 корневых interactive guidance. Векторные контуры прямых вариантов не изменились. Из текстовых инструкций изменился только shortcut поиска: `/` → `⌘K`. Финальная копия SnowUI-source-final-2026-10-17.fig сохранена: 120675 узлов после устранения дубликатов импортированных masters. Все 573 варианта сопоставлены с актуальными masters по имени, типу и идентичности родителя. Канонические Colors совпадают с первой обновлённой копией. 135 вариантов имеют изменения записанных полей; реальные изменения Checkbox/Radio/Search отделены от ссылок на версии переменных и кешированных размеров HUG-текста через экспорт редактора.

Применено: Secondary/Blue и Brand `#33D1FF`, соответствующие акценты и логотип (17 точных контуров, 16 градиентов из SVG редактора); надпись SnowUI также взята из этого экспорта; shortcut и обработка Command/Ctrl-K; удалённый автором нижний логотип Sidebar; SearchPopup с gap 12 и без прежних вертикальных отступов заголовков/групп. Экспорт редактора и реальный браузер подтверждают размер SearchPopup 480×552 в обеих темах. Видимые размеры значков проверяются по экспорту редактора: кешированный размер DefaultIcon после library update не всегда совпадает с размером вектора. Apple/Google оставлены 20px по реальному PNG. Исправлены иконки Projects (закрытая папка) и Account (IdentificationCard). Финальный SVG Form-instances-final-2026-10-17.svg подтвердил новые контуры Checkbox толщиной 2px (галочка и минус) и отсутствие дополнительной hover-заливки Checkbox/Radio; они перенесены в код. Исходные примеры Search и Code Connect используют единый ⌘K.

Повторная оценка исключений:

- Читаемое меню автор исправил: исходные высоты названий теперь 20px, сломанные переносы исчезли. Дополнительное исключение больше не требуется.
- Новая тёмная Primary White/40% не проходит существующие проверки: текст на #333 даёт 3.42:1 вместо 4.5:1; некоторые выбранные controls дают 2.68–2.92:1 вместо 3:1. Попытка принять её вызвала реальные ошибки Storybook/axe; сохранён согласованный доступный Indigo Primary. Светлый cyan текст на белом также не проходит; для него сохранён доступный цвет. Пороговые значения проверок не менялись.
- Traffic by Device: числовая шкала и геометрия исходника автором не исправлены. Сохранена согласованная математически корректная ось; проверены пропорции при resize в Chromium и WebKit.

Последующий точный набор из 106 случаев охватил прежние изменения и все Checkbox/Radio/Form/Table/Search/Dashboard: 85 совпадений, 18 ожидаемых изменений и 3 штатных skips. Все 18 отличий — изображения, без ошибок поведения: новые контуры, ⌘K, иконка папки; у страницы Colors высота выросла на 32px из-за уточнения описания доступной Primary. ## Независимое ревью и публикация

Проверяющий со свежим контекстом последовательно изучил полный diff от ec03d210271df86dcfac5cfa83407aa73784a680 до 4021baff1d3024af86677f885070da525c4f12c2: 922 файла, включая 81 текстовый и 841 бинарный. Проверены все добавки, исходные контуры логотипа/надписи/кольца, 48 первых и все 18 заключительных PNG-пар, их SHA256/CRC/размеры, воспроизводимая генерация шрифтов. Замечание о возврате фокуса Add Data исправлено и повторно проверено; новых дефектов не найдено. Ревью изображений опиралось на контактные листы и подробную выборку; проверяющий не воспроизводил всю матрицу Figma самостоятельно.

В native Figma нет доступных library updates для всех страниц. Полная финальная .fig и экспорты сохранены локально вне Git. Figma сообщает, что локальные изменения синхронизируются после восстановления соединения; облачное сохранение не подтверждено.

До отдельного разрешения пользователя публикация не выполнялась: автоматическая проверка отклонила прежнюю попытку, поскольку прежнее согласие касалось исправлений анимаций. Актуальное разрешение и состояние выпуска указаны ниже.
