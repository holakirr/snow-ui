Checkbox turns an option on or off, or shows that only some of a group is on. It is the Figma "Checkbox" set (Select True / False / Multiple × State Default / Hover), built on the Radix Checkbox.

```tsx
import { Checkbox, Label } from '@holakirr/snow-ui'

<Checkbox id="terms" checked={accepted} onCheckedChange={(checked) => setAccepted(checked === true)} />
<Label htmlFor="terms">Accept the terms</Label>
```

<Primary />

## When to use

- An option in a form that is submitted later: accept the terms, subscribe.
- Several independent options, any number of which can be on.
- A "select all" checkbox over a list, indeterminate while only some items are selected.

## When not to use

- A setting that takes effect at once: use [Switch](?path=/docs/components-input-switch--docs).
- One choice out of a few: [RadioGroup](?path=/docs/components-input-radiogroup--docs), or [Select](?path=/docs/components-input-select--docs) for a longer list.
- A pressed state of a toolbar button: [Toggle](?path=/docs/components-input-toggle--docs).

## Anatomy

1. **Box**: the `<button role="checkbox">`, 28px with an 8px radius. Every prop goes to it.
2. **Mark**: the Figma check (True) or bar (Multiple), drawn to fill the box, `aria-hidden`.
3. **Label** (yours): a [Label](?path=/docs/components-label--docs) with `htmlFor` set to the checkbox's `id`, or a `FormLabel` in a [Form](?path=/docs/components-form--docs) item.

- **Keyboard focus:** the `focus-ring` utility (see Accessibility).
- **Disabled** (`disabled`): a Black/4% box with a Black/10% ring; checked or indeterminate, a Black/10% fill with a Black/40% mark. The Figma set has no Disabled state, so this look is the library's own, visible in both modes.
- **Invalid** (`aria-invalid`, which `FormControl` of [Form](?path=/docs/components-form--docs) sets): the unchecked box gets a Secondary/Red ring, also on hover (no Figma state). A checked box keeps its look.

## Accessibility

- It renders a `<button type="button" role="checkbox">` with `aria-checked` (`"mixed"` when indeterminate). It is in the tab order.
- Clicking an indeterminate checkbox checks it; after that it toggles between unchecked and checked.
- Give it a name: a `Label` with `htmlFor` and the same `id`, or `aria-label` when there is no visible label.
- Inside a `<form>`, a hidden native checkbox carries `name` and `value` (default `on`), so the form submits it.
- `disabled` removes it from the tab order.

### Keyboard

| Key | Action |
| --- | --- |
| Tab | move focus to the checkbox |
| Space | toggle it; an indeterminate checkbox becomes checked |
| Enter | does nothing: Radix prevents it, as WAI-ARIA recommends for checkboxes |

### Deviations from the Figma kit

The full table is in the package README.

| Figma | Library | WCAG |
| --- | --- | --- |
| "Focus" effect: 4px ring, black 4% (1.1:1) | `focus-ring`: the Figma ring plus a 2px `black-80` outline offset by 2px (12.6:1 light, 8.7:1 dark) | 2.4.7, 1.4.11 |
| Checked mark `#FFF` in both modes: 2.07:1 on the dark-mode indigo Primary | the per-mode `white` token: white on black (21:1), black on indigo (10.15:1) | 1.4.3, 1.4.11 |

Known gap, kept from Figma for now: the Black/20% ring of an unchecked checkbox (1.6:1).

## Localization and RTL

- Checkbox renders no built-in strings; the label is yours to translate.
- Put the label after the checkbox in the DOM: in right-to-left text a flex row puts it on the left.

## Controlled and uncontrolled

Pass `defaultChecked` to leave the state to the checkbox, or `checked` with `onCheckedChange` to control it. Both take `true`, `false` or `'indeterminate'`, and `onCheckedChange` receives the same type, so narrow it (`checked === true`) before storing a boolean.

## Do and don't

<DoDont>
<Do>

- Give every checkbox a visible `Label` linked with `htmlFor`.
- Word the label so that checked means yes: "Send me updates".
- Use `'indeterminate'` for a parent whose children are partly checked, and set it from their state.

</Do>
<Dont>

- Don't use a checkbox for a setting that applies at once: use Switch.
- Don't use checkboxes for options that exclude each other: use RadioGroup.
- Don't rely on Enter to toggle it.

</Dont>
</DoDont>
