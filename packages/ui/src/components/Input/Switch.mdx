Switch turns a setting on or off, with an immediate effect. It is the Figma "Switch", built on the Radix Switch.

```tsx
import { Label, Switch } from '@holakirr/snow-ui'

<Switch id="airplane-mode" checked={airplaneMode} onCheckedChange={setAirplaneMode} />
<Label htmlFor="airplane-mode">Airplane mode</Label>
```

<Primary />

## When to use

- A setting that applies as soon as it changes: notifications, dark mode, a feature flag.

## When not to use

- An option that is saved with a form's submit button: use [Checkbox](?path=/docs/components-input-checkbox--docs).
- A pressed state of a toolbar button: [Toggle](?path=/docs/components-input-toggle--docs).
- A choice between more than two options: [RadioGroup](?path=/docs/components-input-radiogroup--docs) or [ToggleGroup](?path=/docs/components-input-togglegroup--docs).

## Anatomy

1. **Track**: the `<button role="switch">`, a 28 × 16px pill with 2px padding and the Figma inner shadow. Every prop goes to it.
2. **Thumb**: a 12px `static-white` circle (white in both modes) with the "Drop shadow 2" effect. It moves 12px towards the end when the switch is on.
3. **Label** (yours): a [Label](?path=/docs/components-label--docs) with `htmlFor` set to the switch's `id`.

## States

<Canvas of={SwitchStories.Checked} />

- **Off:** a Black/20% track; Black/40% on hover.
- **On:** a Primary track; on hover Primary under White/40%.
- **Keyboard focus:** the `focus-ring` utility (see Accessibility).
- **Disabled** (`disabled`): a Black/10% track (Black/20% when on), no inner shadow, the white thumb. The kit dims the whole switch to 20% with the default arrow cursor; 5.x keeps this look, visible in both modes, and the kit's is planned for 6.0.
- **Invalid** (`aria-invalid`, which `FormControl` of [Form](?path=/docs/components-form--docs) sets): a 1px Secondary/Red stroke inside the track, on or off (the kit draws its Error state on text fields; this extends their red stroke).

## Accessibility

- It renders a `<button type="button" role="switch">` with `aria-checked`. It is in the tab order.
- Give it a name: a `Label` with `htmlFor` and the same `id`, or `aria-label` (as the stories do). Name the setting, not the state: "Airplane mode", not "Turn on airplane mode".
- Inside a `<form>`, a hidden native checkbox carries `name` and `value` (default `on`), so the form submits it.
- `disabled` removes it from the tab order.

### Keyboard

| Key | Action |
| --- | --- |
| Tab | move focus to the switch |
| Space, Enter | toggle it (the native `<button>` turns both into a click) |

### Deviations from the Figma kit

The full table is in the package README.

| Figma | Library | WCAG |
| --- | --- | --- |
| "Focus" effect: 4px ring, black 4% (1.1:1) | `focus-ring`: the Figma 4px ring in `black-80` (12.6:1 light, 8.7:1 dark) | 2.4.7, 1.4.11 |
| A 28×16px track | the same track with an invisible 28×24px hit area (`hit-area`) | 2.5.8 |

Known gaps with the default contrast, which keeps the Figma values: the Black/20% off track (1.6:1) and the white thumb on the dark-mode indigo track (2.07:1). With more contrast (`prefers-contrast: more` or `data-contrast="more"`; see [Contrast](?path=/docs/guides-contrast--docs)) the off track is `control-border`, Black/50% (at least 3.93:1; White/50% in dark mode, at least 3.99:1), and the thumb is the per-mode `white`: white on black, black on the dark-mode indigo (10.14:1).

With reduced motion (`prefers-reduced-motion: reduce`) the thumb jumps instead of sliding.

## Localization and RTL

- Switch renders no built-in strings; the label is yours to translate.
- In right-to-left text the thumb moves the other way: on is to the left.

## Controlled and uncontrolled

Pass `defaultChecked` to leave the state to the switch, or `checked` with `onCheckedChange(checked)` to control it. The value is a boolean.

## Do and don't

<DoDont>
<Do>

- Apply the change as soon as the switch changes.
- Give every switch a visible label that names the setting.
- Put the label next to the switch, linked with `htmlFor`.

</Do>
<Dont>

- Don't use a switch in a form that is applied with a submit button: use Checkbox.
- Don't change the label text with the state ("On" / "Off"): the switch shows the state.
- Don't make a switch trigger a confirmation dialog for routine settings.

</Dont>
</DoDont>

It takes the Radix props below, `className` (merged with its classes) and the attributes of the `<button>` it renders; `name`, `value`, `form` and `disabled` also go to the hidden native checkbox.
