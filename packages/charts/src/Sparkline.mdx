A sparkline is a tiny line chart without axes, gridlines or tooltip: the trend next to a number, in a KPI card.

```tsx
import { Sparkline } from '@holakirr/snow-ui-charts'

<Sparkline title="Views, last 7 days" data={[12, 18, 15, 22, 30, 26, 34]} color="indigo" area />
```

## Props at a glance

- `data`: numbers (`null` for a gap), oldest first, or rows with a `dataKey` field.
- `color`: a SnowUI token or any CSS colour (default `primary`); `area` adds a gradient fill (20% to transparent); `dashed`, `strokeWidth` (1.5), `curve` (`smooth` or `linear`).
- `height` (32) and `width` (`100%`, it follows resizes).

## Accessibility

Like the other charts, a sparkline is a `<figure>` named by `title` (or `aria-label` / `aria-labelledby`) and described by `description`, with its values in a visually hidden table (`table={false}` leaves it out; `categoryKey`, `categoryLabel` and `valueLabel` shape it). The graphic itself is hidden. It has no tooltip or keyboard navigation and isn't a tab stop: it illustrates a number that should be text next to it ("7,265, +11.01%"). Without a name a development warning is logged.

## Rendering and RTL

A sparkline is plain SVG, without Recharts (about 2.3 kB, its data table included): a 100 × 100 `viewBox` stretched to the element (`preserveAspectRatio="none"`) with a `non-scaling-stroke` line, so it renders on the server, needs no measuring and keeps its line width at any size. The line is the same monotone curve as the other charts (`curve="linear"` for straight segments); `null` values leave gaps. In right-to-left text (the `dir` prop, the provider's, or the element's) it runs from right to left.
