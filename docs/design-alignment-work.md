## Требования и объём

Довести существующую библиотеку и demo до обновлённого лицензированного SnowUI Figma. Согласованные исключения (контрастные цвета, читаемое меню, корректная числовая шкала) сохранять только если автор не устранил исходную проблему. Проверять композицию, геометрию, типографику, изображения, иконки и состояния.

Объём: существующие компоненты и состояния в обеих темах; Dashboard, Sign In A, Account Settings; отдельная панель Settings со всеми семью разделами. Новые приложения из кита не входят в задачу. Произвольные композиции пользовательского API не являются фиксированным содержимым макета. Для расширений без отдельного макета (Accordion, Alert, AlertDialog, AvatarGroup, Progress, Scheduler, Sheet, Skeleton, Spinner, Sparkline) сверяются общие примитивы, токены и состояния.

## Внесённые исправления

- Inter 3.19 соответствует исходному шрифту Figma; обновлены подмножества, воспроизводимый генератор и лицензия.
- Исправлены геометрия Separator, BadgeDot, RadioMark, Checkbox/Radio, Switch, маркеры Image/Card, минимальная ширина всплывающих меню, стрелка Link, типографика Card и светлый текст Toast.
- Исправлены высоты строк Table A/B, размеры Checkbox в таблицах, исходные портреты, ширина сложенного Sidebar 80px, кнопки 48px, размеры остальных вариантов Sidebar и линия без потери внутренней ширины.
- Icon-toggle Tabs: неактивные значки 16/20/24px; активные с подписью 12/16/20px. Проверены переключение, доступное имя и фактический размер SVG.
- Settings: композиция всех семи разделов, размеры и позиции controls, исходные иконки, фон, цветовые индикаторы, Payment и Plugins. Состояния Plugins сохраняются независимо от Account connected services.
- Account: двухстрочные поля, выравнивание Country/Language, Skill/Status, connected services, email rows, кнопка дополнительных действий, исходные подписи и безопасная деактивация с подтверждением.
- Sign In: геометрия верхней навигации, social buttons, separator, подписи, footer на 48px от нижней границы.
- Dashboard: controls 24/16px, отступ вложенной навигации, параметры области Traffic by Device.
- SearchPopup и Add Data: отдельные исходные композиции, портреты и 9 строк поиска; размеры окна, полей и значков. Фон Add Data скрывается только пока диалог открыт, повторное открытие работает.



## Сверка с обновлённой библиотекой

Пользователь поручил применить library updates и повторно оценить все три исключения: сохранять их только там, где автор не исправил проблему. В native Figma применены 502 обновления и завершающее обновление Colors. После этого Updates с включённым Show updates for all pages сообщает No updates available; доказательство `library-updates-all-pages-complete.png`.

Первая обновлённая полная копия содержит 143598 узлов (предыдущая — 120610). Сопоставлены все 573 прямых варианта, 22 составных экрана и 14 корневых interactive guidance. Векторные контуры прямых вариантов не изменились. Из текстовых инструкций изменился только shortcut поиска: `/` → `⌘K`. Финальная копия SnowUI-source-final-2026-10-17.fig сохранена: 120675 узлов после устранения дубликатов импортированных masters. Все 573 варианта сопоставлены с актуальными masters по имени, типу и идентичности родителя. Канонические Colors совпадают с первой обновлённой копией. 135 вариантов имеют изменения записанных полей; реальные изменения Checkbox/Radio/Search отделены от ссылок на версии переменных и кешированных размеров HUG-текста через экспорт редактора.

Применено: Secondary/Blue и Brand `#33D1FF`, соответствующие акценты и логотип; shortcut и обработка Command/Ctrl-K; удалённый автором нижний логотип Sidebar; SearchPopup с gap 12 и без прежних вертикальных отступов заголовков/групп. Экспорт редактора и реальный браузер подтверждают размер SearchPopup 480×552 в обеих темах. Видимые размеры значков проверяются по экспорту редактора: кешированный размер DefaultIcon после library update не всегда совпадает с размером вектора. Apple/Google оставлены 20px по реальному PNG. Исправлены иконки Projects (закрытая папка) и Account (IdentificationCard). Финальный SVG Form-instances-final-2026-10-17.svg подтвердил новые контуры Checkbox толщиной 2px (галочка и минус) и отсутствие дополнительной hover-заливки Checkbox/Radio; они перенесены в код. Исходные примеры Search и Code Connect используют единый ⌘K.

Повторная оценка исключений:

- Читаемое меню автор исправил: исходные высоты названий теперь 20px, сломанные переносы исчезли. Дополнительное исключение больше не требуется.
- Новая тёмная Primary White/40% не проходит существующие проверки: текст на #333 даёт 3.42:1 вместо 4.5:1; некоторые выбранные controls дают 2.68–2.92:1 вместо 3:1. Попытка принять её вызвала реальные ошибки Storybook/axe; сохранён согласованный доступный Indigo Primary. Светлый cyan текст на белом также не проходит; для него сохранён доступный цвет. Пороговые значения проверок не менялись.
- Traffic by Device: числовая шкала и геометрия исходника автором не исправлены. Сохранена согласованная математически корректная ось; проверены пропорции при resize в Chromium и WebKit.

Текущие проверки после обновлений: полный test — 2042 теста и 49 Python tests; Storybook — 1704 tests; после правок Table/recipe — 51 дополнительный test. Types, lint, UI build, dist, SSR (456 render + 455 hydrate), size budgets, Storybook/registry build прошли. Demo webpack build прошёл; demo E2E 35 и docs 75 прошли. После возврата social icons к исходным 20px demo пересобран; требуется повторить затронутую браузерную проверку.

Первое сравнение Linux screenshots: 988 совпадений, 48 ожидаемых изменений, 56 штатных skips; размеры снимков не изменились. Все 48 пар просмотрены на шести контактных листах. Идёт обновление эталонов; затем требуется финальное сравнение. Новые изменения пока не входят в независимое ревью 88fa39c.
