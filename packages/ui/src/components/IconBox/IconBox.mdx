IconBox sets the size of an icon, avatar or image to one of the Figma icon sizes (12–80px). It can put it on a Black/4% tile (`background`) and add a `badge` on the top end corner. It is the Figma "Icon" component.

```tsx
import { IconBox } from '@holakirr/snow-ui'

<IconBox size={16} background>
  <BellIcon />
</IconBox>
```

<Primary />

## When to use

- Sizing an icon, avatar or image to the kit's icon scale, whatever size the icon was drawn at.
- An icon on a tile, as in the dashboard's notification list.
- A dot or a count on an icon: unread notifications, new messages.

## When not to use

- A picture of a person with a fallback: use [Avatar](?path=/docs/components-avatar-avatar--docs) (inside an IconBox to size it).
- An icon with a label: use [IconText](?path=/docs/components-icontext--docs).
- A clickable icon: use an icon-only [Button](?path=/docs/components-button--docs) with the IconBox in `startContent`.
- A count or a status on its own: use [Badge](?path=/docs/components-badge--docs).

## Anatomy

1. **Box:** a `<span>` with `data-size`. With `background` it is the tile: a Black/4% fill with the size's padding and corner radius.
2. **Icon slot:** a box of exactly `size` pixels. Its child (an icon, an `Avatar`, an `<img>`) is stretched to fill it.
3. **Badge** (`badge`, optional): a box on the top end corner, with `data-slot="badge"`. `badge` (`true`) draws the Figma dot, a Secondary/Indigo circle; any other node, such as a [Badge](?path=/docs/components-badge--docs) with a count, is centred in the same box.

Icons take the text colour: set a `text-*` token on the IconBox or a parent.

`glass` (Figma `Glass=True`) puts the icon on a glass tile instead: White/20% with the "Glass 1" effect, approximated by the `glass-1` utility (a background blur and a soft shadow; CSS has no refraction). It implies `background`, with the same padding and radius except at 80: the Figma Glass tile is 88px there (padding 4, radius 24; the Black/4% one is 104px, padding 12, radius 28). It is meant for icons over a picture or a colour, where the Black/4% tile would disappear. Keep the icon readable on what is behind it (the story uses `text-static-black` over a pastel gradient).

## Accessibility

- IconBox renders `<span>` elements with no role and no name: what assistive technology gets is the child's. Icons from `@holakirr/snow-ui-icons` are `aria-hidden` unless they get an `alt`; give a meaningful icon a text alternative, or put the text next to it (IconText).
- A badge is decorative by default (`aria-hidden`). `badgeLabel` adds visually hidden text inside it ("Unread notifications") and exposes it. This applies to a node in `badge` too: a count badge without `badgeLabel` is hidden from screen readers, so describe the count in `badgeLabel` ("3 unread notifications") or elsewhere.
- The Figma dot is Secondary/Indigo, 2.07:1 on white: don't let it be the only sign of the state. Pair it with `badgeLabel` or visible text.
- IconBox isn't focusable and is not a tab stop. To make an icon interactive, put it in a [Button](?path=/docs/components-button--docs).

None of the package's deviations from the Figma kit apply to IconBox.

## Localization and RTL

- The badge sits on the top end corner: top right in left-to-right text, top left in right-to-left text.
- Mirror directional icons yourself with `rtl:-scale-x-100` (or the icon's `mirrored` prop).
- `badgeLabel` is yours to translate; IconBox renders no built-in strings.

## Do and don't

<DoDont>
<Do>

- Size icons with IconBox instead of `width` / `height` on each icon.
- Use the Figma size of the context: 16 in IconText and next to a `md` button label, 24 for list avatars.
- Give a meaningful badge a `badgeLabel`.
- Recolour the tile with a token class (`bg-color-1`), and keep the icon readable on it.

</Do>
<Dont>

- Don't use sizes outside the scale with arbitrary classes: pick the nearest `size`.
- Don't make the dot the only sign of an unread or changed state.
- Don't put an interactive element in the badge: the badge is decorative unless labelled.

</Dont>
</DoDont>

## Props
