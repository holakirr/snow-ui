# Getting help

SnowUI is maintained by one person in their spare time. Answers are best effort, and a good question or report gets one sooner.

## Read first

- **Documentation:** the Storybook at [snow-ui.holakirr.com](https://snow-ui.holakirr.com): the guides (Getting started, Theming, Localization and RTL) and a usage page for every component, with live examples.
- **Package READMEs:** [`@holakirr/snow-ui`](packages/ui/README.md), [`@holakirr/snow-ui-icons`](packages/icons/README.md), [`@holakirr/snow-ui-charts`](packages/charts/README.md).
- **What is supported:** React, browser and Node.js versions, and which releases get fixes, in the [Versioning and support policy](VERSIONING.md).
- **What changed:** the changelogs ([ui](packages/ui/CHANGELOG.md), [icons](packages/icons/CHANGELOG.md), [charts](packages/charts/CHANGELOG.md)) and the [GitHub releases](https://github.com/holakirr/snow-ui/releases).

## Where to ask

| You have | Go to |
| --- | --- |
| A question: how do I…, why does…, is this the right component for… | [Discussions → Q&A](https://github.com/holakirr/snow-ui/discussions/categories/q-a) |
| An idea, or a component you'd like to see | [Discussions → Ideas](https://github.com/holakirr/snow-ui/discussions/categories/ideas), or a [feature request](https://github.com/holakirr/snow-ui/issues/new?template=feature_request.yml) when it is concrete |
| Something that doesn't work as documented | a [bug report](https://github.com/holakirr/snow-ui/issues/new?template=bug_report.yml) |
| A component that is hard or impossible to use with a keyboard, a screen reader or other assistive technology | an [accessibility issue](https://github.com/holakirr/snow-ui/issues/new?template=accessibility.yml) |
| A security vulnerability | **never in public:** see the [Security policy](SECURITY.md) |
| Something you built with SnowUI | [Discussions → Show and tell](https://github.com/holakirr/snow-ui/discussions/categories/show-and-tell) |

Release announcements are posted in [Discussions → Announcements](https://github.com/holakirr/snow-ui/discussions/categories/announcements).

## A good report

- The versions: `@holakirr/snow-ui` (and icons or charts), React, the browser, and your framework (Next.js, Vite, React Router…).
- A minimal reproduction: the smallest snippet or repository that shows the problem. Check that it still happens with the latest release.
- What you expected, and what happened instead: the error and its stack, or a screenshot.

## Contributing

Fixes and improvements are welcome: [CONTRIBUTING.md](CONTRIBUTING.md) explains the setup, the quality gates and how releases work. For anything larger than a fix, open an issue or a discussion first, so we can agree on the approach before you spend time on it. Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
