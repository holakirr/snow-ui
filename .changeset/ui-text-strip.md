New `TextStrip`, the Figma "TextStrip": a 160×28 pill of centred 14px text, Black/4% with semibold text, or, with `strip`, Secondary/Indigo (with static black text, 10.15:1, where the kit's white is 2.07:1). Long text is cut with an ellipsis; a class changes the width. With more contrast the pill gets the control border and the strip a 2px ring. `asChild` styles a button, a link or a heading; `strip` sets `data-state="on"`.
