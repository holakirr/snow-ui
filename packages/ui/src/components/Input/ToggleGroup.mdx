ToggleGroup is a set of toggles where one (`type="single"`) or any number (`type="multiple"`) can be on. It is the Figma Tab segmented control without panels, built on the Radix ToggleGroup primitive: `variant="pill"` puts the items on a blurred Black/4% track (Figma "Pill"), and so does `filled` (added in 5.2), with a Filled item when on; the other variants have no track (Figma "Solid"). The items are [Toggle](?path=/docs/components-input-toggle--docs)s and take the same variants and sizes.

```tsx
import { ToggleGroup, ToggleGroupItem } from '@holakirr/snow-ui'

<ToggleGroup type="single" variant="pill" aria-label="Sort" value={sort} onValueChange={setSort}>
  <ToggleGroupItem value="down" aria-label="Descending">
    <ArrowsDownIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="up" aria-label="Ascending">
    <ArrowsUpIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

## When to use

- A segmented control that switches a view or a mode: day / week / month, list / grid.
- A set of formatting or filter options, several on at a time (`type="multiple"`).

## When not to use

- Switching between panels of content on the page: [Tabs](?path=/docs/components-tabs--docs). A tab list needs its panels; a view switcher without panels is a ToggleGroup.
- One option on or off: [Toggle](?path=/docs/components-input-toggle--docs).
- Picking one value in a form, with a label per option: [RadioGroup](?path=/docs/components-input-radiogroup--docs); from a long list: [Select](?path=/docs/components-input-select--docs).

## Anatomy

1. **Group** (`ToggleGroup`): a `<div>`; `type` sets single or multiple selection. `variant`, `size` and `iconOnly` pass to every item. With `variant="pill"` it is the track.
2. **Item** (`ToggleGroupItem`): a Toggle with a `value`. Its own `variant`, `size` and `iconOnly` win over the group's.

## Variants

| `variant` | Figma | Group | Item when on | Use for |
| --- | --- | --- | --- | --- |
| `borderless` (default) | Tab "Solid" | no track | Black/4% fill | toolbars, light segmented controls |
| `outline` | none (the library's own, with Button Outline items) | no track; each item has a 0.5px Black/10% stroke | Black/4% fill | options that need a visible shape when off |
| `pill` | Tab "Pill" | a Black/4% track with a 10px background blur | White/80% fill and the `shadow-2` shadow | view switchers |
| `filled` (added in 5.2) | — (the kit's segmented-control examples, as `TabsList variant="filled"`) | the `pill` track | a Filled button: Primary with the per-mode `white` label (white on black; black on the dark-mode indigo, 10.15:1) | a switcher that has to stand out: periods, views |

## Sizes

The items take the Figma Button sizes of [Toggle](?path=/docs/components-input-toggle--docs) (24, 36 and 48px; `md` by default). The group sets the gap and, for `pill`, the track:

| `size` | Gap | `pill` / `filled` track padding | `pill` / `filled` track radius |
| --- | --- | --- | --- |
| `sm` | 2px | 2px | 16px |
| `md` (default) | 4px | 4px | 20px |
| `lg` | 4px | 4px | 24px |

## States

- **Off:** `text-secondary` label and icon; black on hover and keyboard focus, which adds the `focus-ring` utility.
- **On** (`data-state="on"`): a black label and the variant's "on" fill (`filled`: a Primary fill and the per-mode `white` label, which hover and focus keep).
- **Disabled:** `disabled` on the group disables every item; `disabled` on an item disables that one. Disabled items have Black/20% content on a Black/4% tile.

## Accessibility

- `type="single"` renders a `radiogroup` of `radio` items (`aria-checked`); `type="multiple"` renders a `toolbar` of toggle buttons (`aria-pressed`).
- Name the group with `aria-label` or `aria-labelledby`, and every icon-only item with `aria-label` (an unnamed one logs a development warning).
- A single group lets the user turn the last item off (`onValueChange('')`). To keep one item on, control `value` and ignore the empty value.

### Keyboard

The group is one tab stop (roving focus); with `rovingFocus={false}` every item is a tab stop and the arrow keys do nothing:

| Key | Action |
| --- | --- |
| Tab | move into the group, onto an item that is on (otherwise the item focused last, or the first); press again to leave it |
| ArrowRight / ArrowLeft | move focus to the next / previous item, skipping disabled ones; focus wraps around (`loop`, on by default). ArrowDown / ArrowUp do the same unless `orientation` is set, which keeps only its pair of arrows. In right-to-left text ArrowLeft moves to the next item |
| Home / End | move focus to the first / last item (PageUp / PageDown too) |
| Space, Enter | turn the focused item on or off (in a single group, an item turned on replaces the one that was on); the arrow keys don't select |

## Localization and RTL

- ToggleGroup renders no built-in strings: the group and item labels are yours.
- The items follow the text direction, and the arrow keys follow the `dir` of `SnowUIProvider`: in right-to-left text ArrowLeft moves to the next item.

## Composition (asChild)

`ToggleGroupItem` takes Radix `asChild`, as [Toggle](?path=/docs/components-input-toggle--docs) does. The value is `value` (controlled) or `defaultValue` (uncontrolled), with `onValueChange`: a string for `type="single"`, an array of strings for `type="multiple"`.

## Do and don't

<DoDont>
<Do>

- Name the group (`aria-label`) and every icon-only item.
- Use `type="single"` for a view or mode switcher, `type="multiple"` for independent options.
- Keep the items few and short, and of one kind: all icons, or all labels.
- Set `variant` and `size` on the group, not on each item.

</Do>
<Dont>

- Don't use a ToggleGroup to show and hide panels: use Tabs.
- Don't mix `pill` or `filled` items with other variants in one group.
- Don't rely on the arrow keys to select an item: they only move focus.

</Dont>
</DoDont>

## Props

The parts are the [Radix ToggleGroup](https://www.radix-ui.com/primitives/docs/components/toggle-group#api-reference) parts with the Figma styles: they take the Radix props below, `className` (merged with the part's classes) and the attributes of the element they render.

### ToggleGroup

The group, a `<div>` (a `radiogroup` or a `toolbar`): `type` (required) picks single or multiple selection, held in `value` with `onValueChange` (controlled) or `defaultValue` (uncontrolled). `variant`, `size` and `iconOnly` pass to every item. `rovingFocus` and `loop` are on by default.

### ToggleGroupItem

An item, a toggle `<button>` (a `radio` in a single group); `value` names it in the group's value. Its own `variant`, `size` and `iconOnly` win over the group's.
